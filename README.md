# Morse by Ear

Free Morse code courses that teach by sound: https://jayyotatv.github.io/morse-by-ear/

- **Courses**: First Letters, Ear Speed (Koch method), Words on the Air, Sending, First Contact (with a contact simulator).
- **Practice**: 60 second sprint, free copy drills, a practice key that decodes your timing, and a translator.
- **Chart** and **Guide**: every character to hear, timing, method, a 12 week plan and how to get on the air.

Plain HTML, CSS and JavaScript with no build step. Progress is stored in the visitor's browser (localStorage). Works offline after the first visit.
